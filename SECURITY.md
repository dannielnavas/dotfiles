# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| `main`  | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability within this repository or any script/plugin included:

1. **Do not create a public issue.**
2. Send an email to **dannielnavas@gmail.com** with details about:
   - Description of the potential vulnerability
   - Steps or proof-of-concept to reproduce the behavior
   - Affected platform (macOS, Arch, Ubuntu, WSL2)
3. You will receive an initial response within 48 hours.
4. Once addressed, a patched release or commit will be published along with appropriate credits.
